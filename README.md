## What I Learned 🚀

1. **Three.js and WebGL**:  
   I learned how to use **Three.js**, a powerful JavaScript library, to create and manipulate 3D objects in the web browser using **WebGL**. I gained an understanding of how to create geometries like a cube, apply materials, and manage a 3D scene with cameras and lighting.

2. **Canvas API**:  
   I learned how to leverage the **Canvas API** to render dynamic visuals in an HTML element. Using Three.js with the Canvas element helped me understand how the rendering process works and how to integrate interactive 3D graphics into my web projects.

3. **XML Handling**:  
   I learned how to load and parse **XML** data asynchronously. I used this to configure the properties of the cube in the 3D scene, which taught me how external data can be utilized to modify the behavior of objects in a program dynamically.

4. **Asynchronous Programming**:  
   Through the use of `async/await`, I learned how to handle asynchronous operations, such as fetching data from an external XML file. This taught me how to manage errors and ensure my application remains robust even when there are issues with loading data.

5. **Responsiveness in Web Design**:  
   I learned how to handle window resizing dynamically to keep the 3D content responsive across different devices. This included adjusting the size of the renderer and updating the camera properties to ensure the 3D scene fits well on the screen at all times.

6. **Building and Optimizing with Vite**:  
   I learned how to set up and configure **Vite** for a smooth development process. I built my project for production, where Vite optimizes the app, and learned how to prepare it for deployment. This helped me understand how to optimize the code and improve the overall user experience.

7. **Deploying on GitHub Pages**:  
   I learned how to deploy my web project on **GitHub Pages**. I followed the steps of building the project with Vite, setting up my GitHub repository, and deploying the app so it could be publicly accessed. This gave me experience in hosting static web applications.

8. **Project Structure and Best Practices**:  
   I learned how to structure my web project efficiently. I used HTML, CSS, and JavaScript in a modular way, separating concerns and ensuring scalability. This helped me understand how to keep a project organized for long-term maintenance and growth.

9. **Version Control with Git and GitHub**:  
   I gained hands-on experience with **Git** and **GitHub**. I used Git for version control, managing branches, and pushing changes. I also learned how to deploy directly from GitHub Pages, which is a great skill for web project deployment.

10. **Interactive Web Development**:  
   I learned how to create interactive content on the web, specifically 3D graphics. By making the cube rotate on user click, I enhanced the user experience and learned how to incorporate interactivity into a web application.

11. **Documentation and Collaboration**:  
   Through writing a **README.md** file, I learned the importance of clear documentation for both personal reference and for others who may interact with my project. This also taught me how to present my work in a professional, user-friendly manner.
